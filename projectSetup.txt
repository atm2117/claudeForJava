E-commerce project:
  Browse through a List of product.
  Being able to add a product with a price.
  The backend will be a springboot restful api.
  The frontend will be built using NextJS.

Create the project using Spring Initializr:
  groupId: com.arnold.ecommerce
  artifactId: ecommerce-api
  packaging type: jar.
  springboot dependency: Spring web, Spring Data JPA, MySQL Driver SQL , Validation I/O, Spring Boot Actuator and lombok
  SQL:
    From the downloaded resources (C:\Users\arnol\Downloads\resources.zip\resources\project).
    Copy the schema.sql and added into a new 'db' folder under your project.
    Download MySQL workbench
    Download MySQL Server
    Copy the content of schema.sql into MySQL workbench and execute it.
